# Proyecto integrador — Unidad 2: Metodología por objetivo

> Guía completa y reglas generales: [Guía maestra del proyecto integrador](../../01_unidad_1/05_proyecto_integrador/GUIA_PROYECTO_INTEGRADOR.md) (secciones 5 y 7).

## Qué debe lograr su equipo en esta unidad

Definir y probar **cómo se cumplirá cada objetivo específico** formulado en la Unidad 1, y entregar el **informe unificado de las Unidades 1 y 2**: la formulación **corregida** + la metodología.

| Fase | Peso | Fecha | Entrega |
|:---:|:---:|:---:|---|
| 1. Formulación | 3 % | 17-nov | Matriz metodológica (una fila por objetivo) y diagrama del flujo general. |

## Metodología: un bloque por cada objetivo específico

Para **cada** objetivo escriba:

| Elemento | Contenido |
|---|---|
| Objetivo | El de la Parte 1, ya corregido. |
| Entradas | Variables/columnas, tipo y unidad. |
| Procedimiento | Pasos numerados (pseudocódigo o diagrama de flujo). |
| Reglas y parámetros | `if/elif/else`, umbrales y constantes justificados; manejo de faltantes. |
| Estructura del código | Funciones (nombre, parámetros, retorno); uso de `for`/`while`, listas, diccionarios, tuplas, cadenas. |
| Verificación | Casos de prueba con resultado calculado a mano. |
| Salida | Tabla, número, figura o mensaje, y archivo donde se guarda. |

Y, en una sección general: descripción y validación de los datos, flujo completo (lectura → validación → transformación → análisis → exportación) y plan de pruebas.

## Estructura del informe unificado (Unidades 1 + 2)

1. Resumen
2. Capítulo 1 — Formulación (Parte 1 corregida)
3. Capítulo 2 — Metodología (por objetivo)
4. Plan de la Unidad 3: qué resultados se presentarán
5. Referencias (APA 7)
6. Anexos: matriz de coherencia, matriz metodológica, diagramas

## Lista de comprobación

- [ ] La metodología está organizada **por objetivo**, no como texto general.
- [ ] Cada procedimiento se traza a un objetivo, y cada objetivo tiene su procedimiento.
- [ ] Los umbrales y reglas están justificados.
- [ ] Hay casos de prueba con resultados calculados a mano.
- [ ] La Parte 1 incorpora la retroalimentación recibida (indique qué cambió).
- [ ] La fuente de datos no fue modificada; solo se usa 2019–2024.
- [ ] El informe compila y sigue APA 7.
- [ ] Se declaró el uso de IA.
